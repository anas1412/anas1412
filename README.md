### Cyberia AI Studio

An AI automation agency. We build custom AI agents and workflows that take the busywork off your team so it can focus on revenue. Based in Tunisia, working globally.

### Infrastructure

- **[llmproxy-k8s](https://github.com/anas1412/llmproxy-k8s)** - Kubernetes-native LLM proxy. Hands tenants virtual API keys with no database or Redis, just CRDs and Secrets.
- **[envoy-fullstack-k8s](https://github.com/anas1412/envoy-fullstack-k8s)** - Envoy as the single ingress: L7 routing, L4 Postgres proxying, per-route auth, Prometheus → Grafana. k3d + Kustomize.

### Products

- **[Cyberia Space](https://github.com/anas1412/cyberiaspace)** · [cyberiaspace.app](https://cyberiaspace.app) - Visual thinking workspace: the same ideas flow through Spatial canvas, Kanban, Calendar and Directory views. Built-in AI assistant (BYOK).
- **[Cyberia Space Chat](https://github.com/anas1412/cyberia-space)** · [chat.cyberiaspace.app](https://chat.cyberiaspace.app) - Ephemeral real-time chat. Rooms dissolve when you leave, DMs after 24h. React Native + Convex.
